# Checklist de publicación

- [ ] Subir toda la carpeta al servidor.
- [ ] Instalar Node.js 20+.
- [ ] Ejecutar `./install.sh`.
- [ ] Editar `.env` y agregar `OPENAI_API_KEY`.
- [ ] Verificar `CONEXIA_AI_MODEL=gpt-6-luna`.
- [ ] Ejecutar `npm start` o PM2.
- [ ] Comprobar `/api/health`.
- [ ] Configurar dominio y HTTPS.
- [ ] Configurar autenticación de ConexIA+ antes de almacenar datos reales de estudiantes.
- [ ] No subir `.env` al repositorio.
